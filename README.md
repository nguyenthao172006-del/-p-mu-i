# Đập Muỗi Gọi Tên

Game gọi tên ngẫu nhiên: muỗi mang tên bay quanh nhân vật, đếm 3-2-1 rồi đập trúng một con.

## Cấu trúc thư mục

```
index.html                 trang chủ, 3 nút chọn phiên bản
dap-muoi.html              bản thường
dap-muoi-halloween.html    bản Halloween
dap-muoi-gm.html           bản GM của CLB
css/                       giao diện (màu, nút, thẻ tên) của từng trang
js/                        logic game (muỗi bay, đập, âm thanh) của từng trang
img/                       hình nhân vật, tóc, muỗi, sao
```
